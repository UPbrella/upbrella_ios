# 네이티브 iOS WebView 보완

DEBUG에서 홈 개발 서버를 기본으로 사용하며 UPBRELLA_USE_PRODUCTION=1이면 운영 주소를 엽니다. 릴리스는 기존 운영 주소를 유지합니다. 허용 도메인을 부분 문자열로 비교하던 것을 정확한 호스트 또는 하위 도메인 비교로 수정합니다. HTTPS의 신뢰한 메인 프레임에서 카메라 요청만 권한을 묻고 나머지 미디어 요청은 거절합니다. 사진 선택과 카메라 용도의 한국어 설명을 제공합니다.

최신 main의 새 스플래시·아이콘은 그대로 사용합니다. 기존 개발 브랜치의 이전 아이콘 파일을 덮어쓰지 않습니다. 시뮬레이터 Debug 빌드와 plist 검사를 통과했습니다. 실제 기기 카메라/사진 및 OAuth·쿠키 유지 확인, 스토어 배포는 하지 않았습니다.
